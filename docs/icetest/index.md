本页面用于演示和验证对 GoPress 网站内容的编辑与更新流程。您可在此测试 Markdown 格式、代码块展示及链接功能。

## 示例：Go 语言基础代码

以下是一个标准的 Go “Hello, World!” 程序，展示了基本语法结构：

```
package main

import "fmt"

func main() {
    fmt.Println("Hello Go")
}
```

### 代码说明：
- `package main`：定义主程序包，是可执行程序的入口。
- `import "fmt"`：导入标准库中的格式化 I/O 包。
- `func main()`：程序的主函数，执行从这里开始。
- `fmt.Println(...)`：向标准输出打印一行文本。
